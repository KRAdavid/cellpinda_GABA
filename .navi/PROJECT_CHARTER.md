# Project Charter

## Goal Lock

- Project Name: 셀핀다가바 GABA 공개 안내서 공개 배포 품질 고도화
- User Intent: 일반 소비자와 사업자가 GABA를 쉽게 이해하고 공유할 수 있는 공개 사이트를 안정적으로 운영한다.
- Goal Statement: 제품 광고와 분리된 GABA 공개 안내서를 모바일 중심·출처 연결형 정보 경험으로 점검하고, 공개 배포 품질 기준을 통과시킨다.
- Problem Definition: 연구·일상·영상·출처 정보가 많아 방문자가 첫 화면에서 전체 흐름과 연구 결과를 직관적으로 이해하기 어렵고, 공개 배포 품질을 한 번에 재현할 검증 기록이 필요하다.
- Why It Matters: 소비자는 신뢰할 수 있는 흐름으로 GABA를 읽고, 사업자는 과장 없이 설명 자료로 활용할 수 있어야 한다.
- User Decision Enabled: 현재 공개 배포본을 유지할지, 발견된 결함을 보완한 뒤 재배포할지 검증 결과와 잔여 위험을 기준으로 판단한다.
- Scope: 첫 화면, 모바일 반응형, 연구 확장 섹션, 연구 결과 도표, 출처 링크, 전문가 영상 흐름, 공유 경험, 접근성, 정적 번들, 라이브 공개 URL, NAVI 감사·레드팀 기록
- Out of Scope: 제품 판매·구매 CTA, 새로운 임상·효능 주장 생성, 법률·의학적 보증, 비공개 운영 데이터 공개, Safari·실기기 전체 조합의 현장 테스트
- Constraints: 한국어 가독성, 모바일 우선, 제품 독립적 공개 과학 안내, GitHub Pages 공개 URL, 기존 사용자 파일 보존, 근거와 해석의 경계 유지
- Priority: HIGH
- Unknowns: 실제 사용자 인지 부하와 고령 사용자 독해성, Chrome CDP 외 브라우저별 시각 차이, 공개 과학 카피에 대한 독립적인 규제·과학 감수
- Status: LOCKED

## Initial Blueprint

- Final Deliverable: 공개 배포용 GABA 안내 사이트와 재현 가능한 품질 검증·감사 패킷
- Success Criteria: 타입체크·127개 테스트·정적 번들·성능 예산·라이브 200 응답·1440px/390px 화면·런타임 오류·모바일 가로 넘침·핵심 메뉴 상호작용 검증
- Initial TF: 콘텐츠·근거 검토, React/Vite 프런트엔드, 반응형 UX, 접근성·성능 QA, 배포·라이브 검증, 독립 감사·레드팀
- Major Risks: 과학 카피의 효능 오인 가능성, Chrome 중심 시각 검증, GitHub Pages CDN과 실제 브라우저 차이, 새 근거 추가 시 내용 경계가 흔들릴 위험
- Execution Plan: 기준선 검사 → 목표·산출물 잠금 → 위험 통제 산정 → 정적·실행·시각 QA → 필요한 코드 보완 → 독립 감사 → 레드팀 → 잔여 위험과 사용자 결정 기록
- Approval Needed: 현재 사용자의 자동 점검·저장소 보완 요청을 코드·문서 보완 권한으로 기록하며, 외부 과학·규제 감수와 추가 실기기 테스트는 별도 검증 게이트로 남긴다.
