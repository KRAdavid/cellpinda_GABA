# Deliverable Specification

## Deliverable

- Deliverable Name: 공개 배포용 GABA 안내서 및 품질 검증 패킷
- Primary User: 일반 소비자, GABA 자료를 활용하는 사업자, 사이트 운영자
- Usage Context: https://kradavid.github.io/gaba_info/ 공개 페이지를 읽고 공유하거나 배포 전 품질을 확인할 때 사용
- Format: React/Vite 정적 사이트, 연구 결과 시각화 카드, 출처 연결 콘텐츠, NAVI 상태·감사·레드팀 기록
- Status: LOCKED

## Requirements

- Required Sections or Features:
  - 첫 화면에서 수면·회복과 GABA 안내 목적을 이해할 수 있는 히어로
  - 발견의 역사에서 연구 확장, 일상, 수면, 활용, 발효·안전, 출처로 이어지는 자연스러운 흐름
  - 인지·피부·근육·성장호르몬·면역 5개 연구 영역 지도와 연구 카드
  - 연구 대상·관찰 결과·해석·출처를 한 화면에서 읽는 도표형 카드
  - 전문가 영상 선택 즉시 재생, 출처 링크, 공유 흐름
  - 390px 모바일 대응, 가로 넘침 방지, 메뉴·공유 버튼의 실제 상태 변경
  - 제품 광고·구매 유도와 분리된 과학 정보 안내 문구
- Required Data:
  - 승인된 공개 연구 인덱스와 소비자용 요약
  - 연구 카드의 출처·PMID/원문 링크
  - 타입체크·테스트·빌드·성능·정적 번들·라이브 검증 결과
  - 데스크톱·모바일 렌더와 핵심 상호작용 결과
- Quality Requirements:
  - 자연스러운 한국어와 큰 글자 중심의 가독성
  - 제품 독립적이고 과장 없는 공개 과학 안내
  - 출처와 연구 결과의 구분, 관찰 결과와 해석의 구분
  - 정적 사이트 성능 예산과 접근성 계약 유지
  - 자동 검증을 재실행할 수 있는 명령·증거·감사 기록
- Acceptance Criteria:
  - ID: AC-001
    Statement: 공개 URL이 200으로 응답하고 올바른 제목·히어로·정적 번들을 제공한다.
  - ID: AC-002
    Statement: 연구 확장 섹션에 5개 연구 영역과 5개 상세 카드가 데스크톱·모바일에서 표시된다.
  - ID: AC-003
    Statement: 연구 결과가 비교 조건·GABA 조건·핵심 결과·출처와 함께 도표로 이해된다.
  - ID: AC-004
    Statement: 390px 화면에서 가로 넘침이 없고 메뉴 상호작용이 실제 열린 상태로 변한다.
  - ID: AC-005
    Statement: 타입체크, 127개 테스트, 공개 카피·UI·정적 번들·성능 검사가 통과한다.
  - ID: AC-006
    Statement: 제품 독립적 과학 정보라는 경계와 연구 출처 연결이 공개 화면에 유지된다.
  - ID: AC-007
    Statement: 감사와 레드팀이 실행 역할과 분리되어 잔여 위험·추가 검증 조건을 기록한다.
- Prohibited Content or Behavior:
  - 검증되지 않은 효능·치료·성장·치매 예방의 단정
  - 제품 구매, 상담, 판매 전환을 공개 과학 안내의 핵심 CTA로 사용하는 것
  - 실제 연구 결과를 임의로 확대하거나 비교 도표를 효과 크기로 오인하게 만드는 표현
  - 연구 원문으로 이동하기 전 흐름을 끊는 불필요한 메뉴형 중간 화면
- Definition of Done:
  - 위 기준에 대한 실행 증거가 EVIDENCE_REGISTER에 연결된다.
  - 코드 변경이 필요하면 보완 후 동일 QA를 재실행한다.
  - 독립 감사·레드팀 결과와 남은 외부 검증을 상태에 기록한다.
  - 사용자 결정이 필요한 잔여 위험을 숨기지 않고 공개 배포 상태와 구분한다.
