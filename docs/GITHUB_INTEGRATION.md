## 재사용 가능한 범위

연구 제목, DOI·PMID, 원문 연결, 연구 유형 분류는 다음 탐색의 출발점으로 재사용할 수 있다. 연구별 원문을 다시 확인한 뒤 대상·표본·설계·섭취 조건·기간·비교군·정확한 결과·상반 결과·한계·제품 적용 범위를 현재 원장 구조에 맞춰 기록한다. 후보가 긍정 결과가 아니라는 이유로 제외하지 않는다.

복합성분, 프로바이오틱스, 의약품·질환 치료 연구, 동물 및 기전 연구를 GABA 단독 섭취나 해당 판매 제품 결과와 섞지 않는다. 스냅샷 날짜가 최신이라는 이유로 체계적 검색의 완전성이나 모든 논문의 최신 검증을 보장한다고 표현하지 않는다. 원문 PDF 재게시 권한이나 코드·편집물 라이선스는 별도 확인 전 확보되었다고 가정하지 않는다.

이번 단계의 결과는 ‘별도 근거 저장소 읽기 연결 및 후속 원문 후보 확보’다. 소비자 원장, 앱 코드, 제품 효능 주장과 공개 외부 링크는 변경하지 않았다.


## 소비자 사이트 전용 저장소 생성 확인

GitHub CLI 인증 사용자 KRAdavid 확인 후 별도 비공개 저장소 https://github.com/KRAdavid/cellpinda-rhythm 를 생성했다. default branch는 codex/consumer-site, 원격 HEAD는 95502506a345a390cb5e72d4eaf841ae0dedab6b로 git ls-remote와 GitHub 조회에서 확인했다. 기존 연구 인덱스 저장소는 수정하지 않았다.

업로드 소스는 tmp/github-consumer-release의 독립 Git 이력이다. scripts/export-github.mjs가 승인된 공개 claim10개/product2개/review목적지1개만 추출하며, 내부 문서·보류 후기·원래 로컬 Git 이력·비밀 파일은 포함하지 않는다. 업로드 직전 50개 staged 파일에서 실제 운영자 키가 없음을 확인했다. 사본에서 의존성 설치, 테스트28개, production build 통과. 메인 작업 폴더의 원격에 추가해 전체 내부 이력을 실수로 push하지 않는다.

이 저장소는 코드 검토용이며 자동배포는 연결하지 않았다. 후속 변경도 새 공개 소스 사본과 비교해 명시적으로 반영해야 한다. Cloudflare 임시 배포와 별개이며 영구 운영 완료가 아니다.
