- 자동 조치: 공개 원장과 사이트 문구를 변경하지 않는다.
- 다음 회의 결정: 제품 책임자와 표시·콘텐츠 검토자가 최종 승인본·제품 분류·SKU를 대조해 `DONE` 또는 `REWORK`로 전환한다.
