# 일러스트·정보시각화 TF 검토 — 2026-09-17

## 요청과 참여 역할

사용자는 애플처럼 글을 줄이고 직관적인 시각 정보를 늘리며, 일러스트로 바꿀 수 있는 설명은 그림으로 대체하도록 요청했다. 이에 `data/tf-role-registry.json`에 **일러스트·정보시각화 디자이너** 역할을 추가했다. 이번 검토는 AI TF 역할의 코드 기반 검토이며 실제 외부 일러스트 전문가의 참여·자격 확인이나 소비자 조사를 의미하지 않는다.

## 역할별 검토

| 역할 | 검토 의견 | 반영 결정 |
|---|---|---|
| 일러스트·정보시각화 | 카드 제목, 긴 설명, 그래프가 같은 변화를 반복한다. 연구마다 큰 핵심 수치, 비교 그림, 짧은 연구 조건을 중심으로 정리한다. | 긴 결과 문단을 걷고 전후 수치·방향·집단 비교를 시각 중심으로 배치한다. |
| 마케팅·소비자심리 | 40~50대 방문자는 전문 용어가 많은 연구 설명보다 “무엇이 어떻게 달라졌는지”부터 읽기 쉽다. | 큰 변화 숫자와 실생활 단어를 앞세우고, 연구 방법의 긴 설명은 선택해서 연다. |
| 연구·근거 | 뇌파·활력 점수, 혈중 성장호르몬, 제지방량은 서로 다른 지표이며 같은 효과로 합칠 수 없다. | 성장호르몬과 근육 발달을 별도 연구·시각으로 표시하고, 단백질+GABA 병용 조건을 비교 그림에 남긴다. |
| 제품·표시 | 일반 연구를 셀핀다 완제품 시험처럼 보이게 하거나 그림으로 섭취 효과를 암시하지 않도록 해야 한다. | 논문 속 GABA→연구 참여자 결과 경로를 보여주고 제품 정보는 포장 표시로 분리한다. 관찰 연구는 섭취시험이 아님을 표시한다. |
| 스토리·UX·접근성 | 막대 길이만으로 의미를 추측하게 만들면 색각·수치 이해가 모두 어려워질 수 있다. | 값·단위·짧은 라벨을 함께 두고, 모바일에선 한 장면씩 세로로 읽게 한다. |
| QA·감사 | 공개용 그림은 색상과 도형만으로 의미를 전달하지 말고, 접근 가능한 설명과 원문 연결을 남겨야 한다. | 그림에 접근성 라벨, 핵심 수치, 연구 원문 링크를 유지한다. |

## 구현

- 수면 전후 값은 막대 그래프 대신 큰 숫자와 시간 흐름으로 보여준다.
- 수면 두 지표는 각각의 수치와 방향을 한 화면에서 나란히 보여준다.
- 정신 과제 연구는 섭취→대기→과제→뇌파·활력 측정 흐름을 아이콘으로 압축하고, 관찰된 변화는 두 짧은 결과로 표현한다.
- 혈중 성장호르몬은 위약 대비 배수 그림으로, 12주 제지방량은 단백질 단독과 GABA 병용 막대로 분리한다.
- 뇌 영상 관찰 연구는 뇌 신호와 촉각 과제 사이의 관련성을 점선 연결로 나타내며, 섭취 연구와 구분한다.
- 참여 인원·섭취 조건·기간은 사람·섭취·시계 아이콘 옆에 표시하고, 상세 방법·출처는 펼쳐서 확인하게 한다.
- 중복 설명, 불필요한 표식, 반복되는 안내 문구를 제거하되 원문 출처와 연구 조건을 남긴다.

## 시각 표현의 안전 경계

낮은 수치가 항상 개선을 뜻하지 않으므로 수면 잠복기처럼 방향이 명확한 측정값에서만 “짧아짐”으로 적는다. 정신 과제 연구의 “덜 낮아짐”은 집중력 향상이나 스트레스 감소로 번역하지 않는다. 휴식 중 성장호르몬 수치의 차이를 근육 증가 그림과 연결하지 않는다. 제지방량 그림에는 유청단백질과 GABA 병용 조건을 함께 표시한다. 이 모든 연구는 셀핀다 완제품 시험이 아니며, 제품 표시 정보를 별도로 확인하게 한다.
