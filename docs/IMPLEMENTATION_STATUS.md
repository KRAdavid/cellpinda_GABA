# 중간 구현 상태 — 2026-09-10

목표 파일 전체를 읽고 구현을 시작했다. 기존 회의 문서 작성은 progress로 분류한다. 이번 작업도 실제 코드·원장·이미지·테스트를 만들었으므로 progress다. 전체 목표는 아직 완료되지 않았다.

## 2026-09-10 로컬 제품 자료 재점검

1500 단상자·3개입·낱포 인쇄본과 제품 관련 영양성분검사성적서를 외부 자료 폴더에서 찾아 렌더링해 대조했다. 원료 1 kg·10 kg 벌크 라벨은 완제품 표시 근거에서 제외했다. `data/local-material-manifest.json`과 `pnpm run audit:materials`가 파일 존재·수정시각·SHA-256·완제품/벌크 분류를 읽기 전용으로 기록한다. 이 결과로 작업 그래프 B2는 `WAITING`에서 `VERIFYING`으로 이동했지만, 최종 인쇄 승인·제품 분류 확인 전에는 공개 문안을 바꾸지 않는다. B3 후기 권한, C2 Cloudflare 운영 비밀키, E1 주문 대사는 계속 대기한다.

## 2026-09-10 로컬 주문 자료 자동 감사

`data/local-order-manifest.json`과 `pnpm run audit:orders`를 추가했다. 지정 폴더의 주문 파일을 읽기 전용으로 해시하고, CSV에서 상품군·수량·기간·필드 존재만 집계한다. 1500 후보 행과 상품번호 후보를 찾았지만 과거 파일에는 취소·환불 상태 열이 없었고, 스마트스토어 명칭의 457개 통합문서는 암호화 컨테이너여서 비밀번호 없이 열지 않았다. 원본 개인정보와 750 행은 공개 export에 들어가지 않는다. 이 결과로 E1의 입력 탐색은 진전됐지만 판매자 계정·채널상품번호·결제·취소·환불 테스트 응답이 없어 상태는 `WAITING`으로 유지한다.

아래 기존 표는 첫 로컬 검증 시점 기록이다. 최신 변경은 다음과 같다.

## 최신 업데이트 — 목표 실행 운영 MVP

- `?view=ops`에서 한 문장 목표 `공개용 GABA 논문 기반 마스터 인덱스`를 입력하면 Goal Contract, 5개 TF 스트림·10개 역할, 6단계 업무 그래프를 자동 생성한다.
- 선행 작업은 브라우저 샌드박스에서 실행되고, 외부 공개·구매·법적 약속이 필요한 마지막 단계는 승인 토큰 없이는 실행되지 않는다.
- 완료·대기 작업, 승인 게이트, 이벤트 원장을 포함한 JSON 결과 보고서를 복사하거나 다운로드할 수 있다.
- `public/data/gaba-master-index.json`은 승인된 연구 원장에서 생성되며 공개 연구 8건의 소비자 요약·희망적 연결 문장·한계를 함께 제공한다.
- 이 MVP는 실제 운영 계정·서버 영속 감사 로그·승인자 인증을 대체하지 않는다. 목표별 실행 기능을 운영 서버로 이식하는 일이 다음 게이트다.

## 검증

- TypeScript 검사 통과.
- Node 7개 테스트 통과: 체크 규칙 5개, 서버 통합 2개. 서버 통합은 인증·공개 필터·충돌·영속·중복 이벤트·개인정보 필터·Origin·요청 제한을 포함.
- Vite production build 성공. 이 결과는 배포 성공을 뜻하지 않는다.
- Browser plugin not available. 런타임 제공 Playwright Chromium으로 검사.
- 1440×960 데스크톱, 390×844 홈, 360×800 제품·메뉴 확인. 가로 넘침 없음.
- 체크→결과→PNG 저장→공유 URL 직접 진입 확인. 관리자 토큰 로그인→문구 선택→이력·분석 렌더 확인.
- 최초 API 403 발견: loopback 개발 Origin 4개만 정확히 허용하도록 수정. 재시작 후 동일 흐름 오류0.
- 브라우저 QA 과정의 이벤트는 로컬 개발 DB에만 기록된다. 실제 소비자 통계가 아니다.
