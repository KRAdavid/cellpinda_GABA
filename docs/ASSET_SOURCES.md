## 사용 범위

사용자가 자신의 셀핀다 제품 홍보 사이트 제작을 요청한 맥락에서 공식 브랜드 상품 이미지를 확보했다. 이 기록은 제3자에게 저작권이나 자유 재배포 라이선스가 부여됐다고 주장하지 않는다. 원본 저작권은 각 권리자에게 있으며 브랜드 사이트의 제품 식별 목적에 사용한다. 이미지가 공식몰에 게시됐다는 사실과 사진에 보이는 인증 마크의 현재 유효성은 별개다. 인증 마크를 따로 추출해 보장 배지로 사용하거나 이미지를 제품 효능의 증거로 쓰지 않는다.

현재 사진은 앞면이다. 원재료명 표기의 가바100%와 분석 순도를 동일시하지 않는다. 법적 제품 분류·사용법·주의사항·제조정보를 확인하려면 뒷면 표시사항을 별도로 대조해야 한다.
