현재 공개 저장소와 GitHub Pages, 공개 콘텐츠 JSON, 광고·근거 문구, 제품·후기 경로, 게임 시작과 결과, 정적 배포 및 Worker 배포 조건을 점검했다. 검토자는 소비자 마케팅·여정, 연구 문구·근거, 출시·기술 감리 역할로 나눴다. 이는 AI 역할 기반 교차 검토이며 외부 자격 전문가의 회의나 소비자 조사·법률 승인으로 간주하지 않는다.

## 배포 판단과 남은 게이트

GitHub Pages 정적 사이트는 공개 가능하지만 전체 제품 운영 플랫폼은 미완료다. 현재 공개 `/api/health`와 `/api/content`는 404이며 Worker/D1이 연결되지 않았다. 응답 헤더도 HSTS 외 CSP, X-Content-Type-Options, Referrer-Policy, Permissions-Policy를 라이브에서 확인하지 못했다.

티저는 `PREVIEW/HOLD`이며 공개 미디어 파일·자막·권리·표시 승인 증거가 필요하다. 사이트 안에 공개 동의를 받은 실제 후기 인용은 없다. 현재 가격·재고는 스마트스토어에서 확인하도록 남겼다. 실제 주문·취소·환불 대사, 최신 포장 표시사항, 보안 헤더, 외부 전문가·소비자 사용성 테스트도 운영 출시 게이트다.

과거 공개 Git 이력에 남은 경로를 완전히 제거하려면 이력 재작성과 원격 force push가 필요하다. 이 작업은 다른 협업자의 clone·태그·링크에 영향을 줄 수 있으므로 별도 영향 분석과 명시적 승인을 받기 전 수행하지 않는다.

### 2026-09-19 후속 근거·제품 표시 감리

- 스크립트를 쓰지 않는 기본 HTML에 승인 보류된 체성분 연구 주제가 섞여 있던 문구를 승인된 11명 성장호르몬 연구 설명으로 바로잡았다.
- 2020년 문헌고찰은 소비자 화면에서 연구 범위만 안내한다. “연구마다 결과가 달랐다”는 요약은 공개 데이터에서 빼고, 참여자·섭취 조건·측정 항목을 다룬다는 설명과 출처·관계 공개는 유지한다.
- 소비자용 제품 화면·공유 카드·정적 공개 데이터에서 포당 1,500mg 및 총 45g 숫자를 뺐다. 확인된 제품명, 30포, 기타가공품 분류와 SmartStore 링크만 보인다. 현재 승인된 포장·성분표를 받기 전에는 1,500mg이 GABA 활성성분량인지 낱포 총량인지 화면에서 단정하지 않는다. 제품 내부 원장의 수치는 공개 UI/API에 내보내지 않는다.
