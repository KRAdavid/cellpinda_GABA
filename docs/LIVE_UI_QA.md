## 2026-09-12 로컬 API 원장 동기화 QA

로컬 API를 최신 원장으로 재시작한 뒤 Chromium Playwright로 1440×1000과 390×844 화면을 확인했다. 두 화면 모두 승인 연구 카드 8개가 각 4개 시각 타일(`참여 규모·기간·비교·살펴본 신호`)을 표시하고, `한눈에 이해하기`와 `숫자와 맥락을 더 보기` 라벨을 사용한다. 두 화면에서 750, 공식몰 링크, `제한적·매우 제한적·정량 메타분석·다만 GABA만의 효과` 문구가 0건이며, 지정 스마트스토어 상세 링크 6개, 가로 오버플로 0, 콘솔·페이지 오류 0을 확인했다.

이 검증은 기존 SQLite의 과거 행을 지우지 않고 서버 시작 시 현재 원장과 대조해 공개 projection을 갱신하는 동기화 경로까지 포함한다.

`?view=ops` 라우트는 로컬 운영 주소에서만 렌더링하도록 `App.tsx`의 호스트 경계를 고정했다. 소비자 메뉴에는 계속 내부 경로가 없고, GitHub Pages 같은 공개 호스트에서는 같은 쿼리를 직접 입력해도 TF 운영판이 열리지 않는다. 로컬 `127.0.0.1:5173/?view=ops`에서는 Goal Contract·TF·업무 그래프·결과·승인 보고와 공개 운영 스냅샷을 확인할 수 있다.

`validate:ui-contract`, `typecheck`, production build가 통과했으며 운영 목표의 공개 제품·후기 CTA는 지정한 스마트스토어 상세 링크를 유지한다.

## 2026-09-12 익명 사용성 측정 선택 QA

소비자 페이지 하단에서 `측정 허용`과 `측정하지 않기`를 선택할 수 있고, 선택하지 않은 상태에서는 익명 이벤트 요청이 발생하지 않는지 확인했다. 허용 후에는 방문 이벤트가 한 번만 이어지며, 거절 후에도 리듬 체크·연구 카드·제품 비교·후기·스마트스토어 CTA를 사용할 수 있다. 설정 변경은 브라우저 로컬 저장값으로 유지되고, 저장소 접근 오류에서는 기본값이 측정하지 않기로 동작한다.

개인정보 경계 문구(`이름·연락처·문항별 답변은 보내지 않습니다.`)와 동의 UI의 모바일 배치를 계약 검사로 고정했다. `validate:ui-contract`, `typecheck`, 전체 79개 테스트, production build가 통과했다.

패널은 푸터 링크와 같은 행에 섞이지 않고 전체 폭의 별도 행으로 표시되며, 390px 화면에서도 가로 넘침 없이 배치된다.
