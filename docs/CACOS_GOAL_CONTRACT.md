# 셀핀다가바 운영 목표 계약

기준일: 2026-09-10. 이 문서는 `셀핀다_AI기업_운영체제_상세설계서_v1.0.docx`의 목표 중심 운영 원칙을 현재 셀핀다가바 사이트에 적용한 실행 계약이다.

## 목표 해석

현재 목표는 원료 B2B 예시를 그대로 실행하는 것이 아니다. 사용자가 확정한 제품 범위와 기존 사이트 작업을 기준으로, **완제품 셀핀다 가바 1500을 중심으로 소비자가 자기 상태를 돌아보고 GABA와 발효 기술을 이해한 뒤 제품 경험·후기 원문·스마트스토어 구매·결과 공유로 이어지는 공개 사이트를 운영하는 것**으로 확정한다.

단종 제품은 현재 목표 범위에서 제외한다. 연구·원료·후기 자료는 완제품 판매 문구와 분리하며, 특정 연구가 완제품 효과를 보장하는 것처럼 연결하지 않는다.

## 성공 기준과 현재 판정

1. 공개 제품은 `gaba1500` 1개만 유지한다. 현재 충족했다.
2. 데스크톱과 390px 화면에서 제품·이미지·후기 원문 링크가 작동하고 가로 넘침이 없어야 한다. 현재 충족했다.
3. 제품 구매 진입은 스마트스토어로 연결한다. 현재 충족했다.
4. 연구·제품 사실·후기 목적지를 분리하고 권한 없는 후기 인용을 막아야 한다. 구조는 충족했지만 권한 있는 실제 후기 자료는 추가 검토가 필요하다.
5. 실제 구매 전환은 주문·취소·환불 대사 전까지 미완료로 둔다.

## 운영 방식

목표를 작업 목록으로만 관리하지 않고, `data/task-graph.json`의 의존성 그래프로 관리한다. `A 소비자 여정`, `B 근거·표시 검토`, `C 배포·데이터 운영`, `D 자율 운영 코어`, `E 커머스·판매처 운영`의 작업 흐름마다 실행 리드와 독립 검증자를 둔다. `pnpm run goal:next`가 선행 작업을 확인하고 계약에 없는 stream·순환 의존성을 차단해 바로 시작할 수 있는 작업과 외부 입력 때문에 기다리는 작업을 분리한다. 완료는 작업이 끝난 시점이 아니라 acceptance 결과와 검증 증거가 연결된 시점으로 판정한다.

대외 문구·제품·후기·연구는 승인 원장과 공개 출처를 통과해야 한다. 조회와 내부 초안은 자동화할 수 있지만, 대외 약속·지출·법적·비가역 행동은 대표 또는 지정 책임자의 승인을 거친다. 외부 응답을 기다리는 작업은 대기 상태로 기록하고 독립 작업은 계속한다.
