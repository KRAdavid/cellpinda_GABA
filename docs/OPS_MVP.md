# 운영 MVP — 공개용 GABA 논문 마스터 인덱스

기준일: 2026-09-10

이 MVP는 한 문장 목표를 `Goal Contract → TF → 업무 그래프 → 샌드박스 실행 → 결과·승인 보고`로 바꾼다. 공개 사이트의 실제 연구 데이터는 승인 원장 `data/content-ledger.json`에서 생성되며, 빌드 시 `public/data/gaba-master-index.json`으로 export한다.

## 실행 방법

1. `?view=ops` 화면을 연다.
2. 목표 문장을 입력하고 **Goal Contract 자동 생성**을 누른다.
3. 생성된 목표·성공 기준·중단 조건과 TF 역할을 확인한다.
4. `READY` 업무를 샌드박스에서 실행한다. 완료된 선행 작업이 다음 작업을 연다.
5. 외부 약속 위험이 있는 공개 배포 단계는 승인 요청으로 멈춘다.
6. 결과·감사 로그·승인 상태를 JSON으로 복사하거나 내려받는다.

## 공개 인덱스 계약

`gaba-master-index.json`에는 승인된 `research-*` 레코드만 포함한다. 각 레코드는 질문, 연구 설계, 대상, 표본, 용량, 기간, 비교, 측정 지표, 관찰 결과, 소비자 요약, 생활 연결 문장, 한계, 완제품 적용 범위와 공개 원문을 가진다. 철회·보류·공개 URL이 없는 자료는 export하지 않는다.

## 운영 경계

현재 화면은 외부 게시·구매·법적 약속을 실행하지 않는 샌드박스다. 브라우저 상태만으로 실제 승인·감사·운영 데이터베이스를 대체하지 않는다. 실제 운영 전에는 관리자 인증, 서버 영속 감사 로그, 백업·복구, 책임자 승인 연결이 필요하다.
