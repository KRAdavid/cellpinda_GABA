# 운영 MVP — 공개용 GABA 논문 마스터 인덱스

기준일: 2026-09-10

이 MVP는 한 문장 목표를 `Goal Contract → 목표별 TF → 업무 그래프 → 샌드박스 실행 → 결과·승인 보고`로 바꾼다. 공개 사이트의 실제 연구 데이터는 승인 원장 `data/content-ledger.json`에서 생성되며, 빌드 시 `public/data/gaba-master-index.json`으로 export한다.

## 실행 방법

1. `?view=ops` 화면을 연다.
2. 목표 문장을 입력하고 **Goal Contract 자동 생성**을 누른다.
3. 생성된 목표·성공 기준·중단 조건과 TF 역할을 확인한다.
4. `READY` 업무를 샌드박스에서 실행한다. 완료된 선행 작업이 다음 작업을 연다.
5. 외부 약속 위험이 있는 공개 배포 단계는 승인 요청으로 멈춘다.
6. 결과·감사 로그·승인 상태를 JSON으로 복사하거나 내려받는다.

화면은 먼저 Worker·D1의 `/api/ops/runs/:runId`에 세션 스냅샷을 저장하고, API가 없는 GitHub Pages 정적 환경에서는 `localStorage`로 폴백한다. `runKey`는 브라우저가 생성하는 샌드박스 세션 키이며 운영자 인증 토큰이 아니다. 서버 스냅샷은 30일 후 만료되고, 모든 저장은 revision과 감사 행으로 남는다. 따라서 이 기능은 재개 가능한 운영 MVP이며 법적·배포 승인 원장을 대체하지 않는다. JSON 보고서에는 계약 스냅샷, 작업별 수락 기준, 작업별 증거, 감사 이벤트가 포함된다.

## GABA 목표 TF

현재 목표에는 TF 리드·AI 비서실, 연구·제품 근거, 마케팅·소비자심리, 제품·품질, 표시·규제 검토, 데이터·성과, 스토리·UX·프런트, 품질감사관을 배정한다. 각 역할은 책임 결과와 권한 범위를 갖고, 품질감사관은 실행 담당과 독립적으로 둔다. 회의는 정기 잡담이 아니라 근거·가정·반대 의견·대안·승인 필요 여부·다음 조치를 기록해야 할 때만 연다.

## 공개 인덱스 계약

`gaba-master-index.json`에는 승인된 `research-*` 레코드만 포함한다. 각 레코드는 질문, 연구 설계, 대상, 표본, 용량, 기간, 비교, 측정 지표, 관찰 결과, 소비자 요약, 생활 연결 문장, 한계, 완제품 적용 범위, 공개 원문, 검토일과 근거 해시를 가진다. 필수 필드·소비자 문장·공개 HTTPS 출처가 없는 자료, 철회·보류 자료는 빌드에서 export하지 않는다.

## 운영 경계

현재 화면은 외부 게시·구매·법적 약속을 실행하지 않는 샌드박스다. 실행 버튼은 상태 전환 예시와 로그를 만들 뿐, 원문 검토·외부 결과·독립 검증을 실제로 수행했다는 증거가 아니다. 보고서에도 `sandbox_simulation_only`가 표시된다. 서버 D1 저장은 재개와 변경 이력 보존을 위한 운영 보조 계층이며 관리자 인증·권한 결정을 대신하지 않는다. 실제 운영 전에는 관리자 인증, 서버 영속 감사 로그, 백업·복구, 책임자 승인 연결이 필요하다.
