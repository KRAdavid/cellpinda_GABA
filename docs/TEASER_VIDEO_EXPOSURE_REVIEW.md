## 권장 노출 위치

티저는 현재 홈의 공감형 히어로와 1분 리듬 체크를 대체하지 않고, 선택형 이야기 입구로 배치한다.

1. **히어로 보조 CTA** — `발효가바 이야기 영상 보기`를 두 번째 버튼으로 둔다. 확인되지 않은 재생 시간을 CTA에서 약속하지 않으며, 첫 CTA는 `1분 리듬 체크`를 유지한다.
2. **인트로 스트립 다음** — `발효가바를 만드는 과정 영상 보기` 카드로 영상과 포스터를 노출한다. 이 위치는 ‘나의 상태 발견’ 다음, GABA 상세 설명 전에 해당한다.
3. **영상 종료 화면** — `GABA를 한 문장으로 이해하기`와 `내 하루 리듬 체크` 두 경로를 제공한다. 영상 재생만으로 제품 효능을 암시하지 않는다.

현재는 티저 페이지를 홈 안의 iframe으로 즉시 재생하는 선택형 카드로 운영한다. 외부 페이지가 임베드를 거부하거나 Cloudflare 확인 화면을 반환하는 경우에만 대체 링크를 제공한다. 카드에는 영상의 역할과 연구·제품 효능을 보장하지 않는다는 설명을 함께 두고, 최종 공개 전에는 포스터·자막·텍스트 대체 설명을 보강한다.

## 공개 전 영상 승인 기준

- 시작 3초 안에 `오늘, 내 뇌는 쉴 틈이 있었을까?` 또는 이에 준하는 공감 문장이 나와야 한다.
- 제품이 **셀핀다가바 완제품**임을 보여 주고, 원료·발효 공정·연구 자료를 완제품 효능으로 이어 붙이지 않는다.
- `잠이 좋아진다`, `불안이 줄어든다`, `뇌를 진정시킨다`, `치료`처럼 일반식품의 효능을 단정하는 표현은 사용하지 않는다.
- 연구 장면이 들어가면 연구 대상·조건·한계와 `셀핀다가바 완제품의 효과를 보장하지 않음`을 영상 또는 바로 이어지는 설명에서 확인할 수 있어야 한다.
- 마지막 3~5초에는 브랜드, 제품 확인 경로, `근거와 표시사항 보기` 또는 `1분 리듬 체크` CTA를 함께 둔다.
- 음소거 자동재생은 허용하되 소리 자동재생은 하지 않는다. `playsinline`, 재생/일시정지/음량/자막 제어, 키보드 접근, `prefers-reduced-motion` 대체를 제공한다.
- 포스터 이미지와 전체 대본/자막을 별도 제공하고, 제품 사진·연구 이미지·음악·인터뷰의 사용권을 기록한다.

## 노출 측정

영상 노출과 실제 전달을 구분해 다음 이벤트를 익명 집계한다.

| 이벤트 | 의미 |
|---|---|
| `teaser_impression` | 영상 카드가 실제 화면에 들어온 횟수 |
| `teaser_play` | 페이지 안 iframe이 재생 화면을 로드한 횟수 |
| `teaser_progress_25/50/75` | 재생 위치 도달 신호 |
| `teaser_complete` | 끝까지 재생된 신호 |
| `teaser_caption_opened` | 자막을 켠 행동 |
| `teaser_cta_clicked` | 영상 뒤 리듬 체크·GABA 설명으로 이동한 행동 |
| `teaser_exit` | 중도 이탈 신호 |

외부 SNS에 실제 게시·전달됐다고 해석하지 않으며, 개인 답변·이름·계정·영상 URL의 임의 쿼리를 저장하지 않는다.

## 공개 전 필요한 입력

1. 로그인 없이 접근 가능한 최종 URL 또는 공개 MP4/HLS 주소
2. 영상 파일·포스터·자막/대본·총 길이·음원과 이미지의 사용권
3. 영상에 표시한 제품명·내용량·표시사항의 현재 확인본
4. 연구·특허·발효 공정 장면별 출처와 완제품 적용 여부
5. 영상 마지막 CTA의 목적지와 캠페인 측정 기간

URL 접근은 공개 상태로 확인했지만, 비로그인 360px 모바일 재생·소셜 미리보기·전체 자막/대본·권리·표시사항·CTA는 아직 승인되지 않았다. 이 항목을 확인해야 실제 공개 노출로 전환할 수 있다.

## 운영 게이트

`data/teaser-manifest.json`이 티저의 현재 상태를 단일하게 기록한다. 현재 상태는 `PREVIEW`이며 `publicPreviewUrl`은 선택형 미리보기 링크, `publicMediaUrl`은 최종 공개 미디어 주소로 구분한다. `pnpm run validate:teaser`는 지정된 `public/data/teaser-preview.json` 외에는 내부 검토 URL이 `src/`, `public/`, `index.html`에 새어 나오지 않는지 확인한다. 최종 공개 승인으로 전환하려면 브라우저 애니메이션 URL 또는 로그인 없는 HTTPS 미디어 주소, 승인자·승인일, 자막·권리·표시사항 증거를 함께 추가하고 위 승인 기준을 다시 통과해야 한다. 기술 접근 성공만으로 B4 게이트를 완료 처리하지 않는다.
