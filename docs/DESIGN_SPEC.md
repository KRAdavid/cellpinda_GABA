# 디자인 기준과 의도적 조정

2026-09-10 이미지 생성 도구로 주요 화면 6종 및 독립 생활 이미지 제작. 사용자가 자동 의사결정과 지속 제작을 요청했으므로 PM이 내부 구현 기준으로 채택. 사용자 디자인 승인 완료라는 의미는 아님.

기준: 흰색 #fff, 진한 초록 #18382b, 강조 #158457, 세이지 #e8f1e7, 경계 #d9e5dc. 본문 sans, 제목 굵은 sans. 너비1280, 좌우40px(모바일20), 구역간96px, 제목72/48/32/24, 본문18px, 작은정보14px. 순서 홈→리듬체크→GABA 이해/근거→발효→제품→후기/챌린지.

시안은 구조와 공간의 기준이며 다음 생성 오류를 채택하지 않는다: 임의 내비게이션·회원가입·새 브랜드 문구, 실제와 다른 패키지, 잘못 생성한 연구 저자·결과, 가짜 후기·승인 날짜. 실제 제품 이미지를 사용하며 문안은 사용자 목표와 검토된 원장이 우선한다. 리듬 결과 미리보기는 실제 결과와 혼동하지 않도록 완료 이후에만 제공한다. 시안의 HPLC/현재균주 연결 등 미확인 내용은 구현하지 않는다.

아이콘은 lucide outline 20px 1.8stroke, 화살표·다운로드·공유·외부링크·체크만 기능에 맞게 사용. 생성 시안에 임의 삽입된 장식 아이콘은 제외.

브라우저 렌더와 시안의 비교는 기능 통합 후 수행한다. 현재 시점에는 완성도 검증 전이다.
