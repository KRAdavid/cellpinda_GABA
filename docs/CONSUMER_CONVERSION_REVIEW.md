# 소비자 관심·이해·체험 의향 재검토

2026-09-10. 현행 구현을 마케팅·소비자 심리, 근거 편집, UX 역할의 AI 에이전트가 독립 검토하고 제안에 대한 반론·수용을 교환했다. 실제 전문가 섭외나 소비자 조사 결과가 아니다.

## 판단

관심을 끄는 체험 기능과 상세 연구는 구현돼 있다. 그러나 첫 화면의 제품 정체, 연구 조건의 기본 노출, 실제 사용을 상상하게 하는 정보가 약하다. 후기 영역은 가바 750·1500 공식몰 원문 연결을 제공하지만, 사용자가 요구한 풍부한 실제 후기 경험은 실제 권한 자료가 들어오기 전까지 완성되지 않는다.

목표 흐름은 공감 → 쉬운 GABA 이해 → 연구의 발견과 한계 → 셀핀다 제품 사실 → 실제 사용 경험 → 첫 사용 정보 → 구성 선택·구매·공유다. 리듬 체크는 선택 가능한 진입 경로이며 제품 필요성이나 용량을 판정하지 않는다.

## 역할 간 토론과 결정

| 관점 | 제안·반론 | 결정 |
|---|---|---|
| 마케팅·소비자 심리 | 생활 습관 사이트로만 보일 수 있다. 제품 실물과 제품·후기 바로가기가 필요하다 | 첫 화면에 제품명과 기존 실물, 직접 이동 경로 추가 |
| 근거 편집 | 연구 숫자만 먼저 보이면 완제품 효과를 입증한 듯 읽힐 수 있다 | 승인 요약·제품 적용 한계를 유지하면서 대상·규모·기간을 기본 노출 |
| UX | 구매 링크 뒤의 후기를 찾기 어렵다. 후기 섹션을 최종 선택 앞으로 옮기자 | 메뉴·첫 화면·750/1500 제품 카드에 제품별 후기 경로 추가. 실제 사례 확보 후 제품 사실→후기→최종 선택 재구성 |
| 근거 편집 | 후기 목적지는 공식몰 원문으로만 연결해야 한다 | 750·1500 상품번호와 공식 호스트를 검증하고, 원문 복제 없이 목적지만 공개 |
| 마케팅·소비자 심리 | 링크 개선만으로 체험 의향 상승을 주장할 수 없다 | 실제 소비자 과제로 이해·망설임·체험 의향을 검증 |

## 쉬우면서 밀도 있는 근거

각 주제의 첫 문장은 소비자의 질문에 답한다. 기본 카드에는 연구 질문, 쉬운 결과 요약, 대상·규모·기간, 해당 판매 제품에 적용할 수 있는 범위를 둔다. 펼침 안에는 제형·용량·대조군·측정 지표·정확한 결과·통계·한계·원문을 둔다.

체내 GABA 역할, 경구 섭취 연구, 셀핀다 완제품 자료를 구분한다. 전후 변화와 위약 대비 차이는 별도로 설명한다. 연구를 제품 체험 성공 사례로 연결하지 않는다. 새로운 종합 효능 문구는 별도 근거 검토 후 원장에 승인된 경우에만 공개한다.

## 후기를 핵심 콘텐츠로 만드는 설계

대표 사례는 선택 배경 → 사용 제품 → 실제 사용 상황 → 좋았던 점·아쉬운 점 → 다음 구매자가 알아둘 점 순서로 읽는다. 원문에 없는 정보를 채우거나 긍정적인 표현으로 고치지 않는다. 자동으로 넘어가는 슬라이드 대신 읽고 펼칠 수 있는 카드와 목록을 제공한다.

| 공개 카드 | 내부 운영 원장 |
|---|---|
| 제품·옵션, 작성일, 확인된 사용 기간 | 원본과 발췌 대조, 제품 식별 근거 |
| 맥락을 보존한 인용 또는 명확히 표시된 편집 요약 | 재게시 권한 증거, 허용 채널·기간·작성자 공개 범위 |
| 제품 제공·대가 관계, 발췌 여부, 원문 | 구매 확인 방법, 경제적 관계 확인 기록 |
| 확인된 경우에만 구매 확인 표시 | 검토자·수정 사유·공개/보류/철회 이력 |

사용 기간 등 빠진 정보는 추정하지 않는다. 긍정·혼합·부정 경험에 같은 공개 기준을 적용한다. 선별 후기의 수를 전체 고객 수로, 선별 평점을 전체 만족률로 표시하지 않는다. 건강 변화 문장은 사용권 확보와 별도로 제품 광고 문안으로 검토해야 한다.

후기 운영 순서: 접수 → 원문·권한·제품 연결 확인 → 인용 편집 → 내용 교차 검토 → 게시 → 정정·철회 대응. 후속 구현에서 운영자의 초안 접수, 원문·권한·맥락·제공 관계·광고 표현 확인 기록, 공개/보류 및 카드 발행을 추가했다. 단일 운영자 접근 키로 남기는 기록이며 여러 독립 검토자의 승인 권한을 강제하는 시스템은 아니다. 실제 권한 증거의 진위와 문안 적합성은 담당자가 확인해야 한다.

## 필요한 실제 팀과 자료

| 담당 | 산출물 |
|---|---|
| 전문 마케터·브랜드 책임자 | 주요 소비자 가설, 페이지 문안, 체험·구매 제안과 실제 운영 조건 |
| 소비자 심리·사용자 조사 담당 | 첫 화면 이해, 기대 효과, 후기 신뢰, 구매 망설임 관찰 |
| 제품 담당·고객 응대 담당 | 현재 포장 전면·뒷면·개별 포, 사용·보관 표시, 개봉 사진, 반복 질문 |
| 근거 연구·식품 표시광고 검토 담당 | 연구 조건·결과·완제품 연결 범위 및 공개 문안 검토 |
| 후기 운영·권한 담당 | 사용 가능한 실제 후기, 원문·재게시 범위·제품·작성일·제공 관계 |
| UX·카피·시각 디자인 | 이야기 흐름, 후기 카드, 첫 사용 안내, 모바일 탐색 |
| 개발·QA·분석 | 승인 데이터만 공개, 수정·철회 반영, 공유·구매 연결, 지표 검증 |

후기 3~5건을 시작 자료로 준비하되, 이를 전체 고객을 대표하는 표본으로 해석하지 않는다. 현행 제품의 맛·크기·섭취법은 직접 자료 확인 후 작성한다. 실제 체험 상품이나 프로그램이 없다면 무료 체험 신청 버튼을 만들지 않는다.

## 소비자 검증

1. 첫 화면 15초 후 어떤 제품·사이트인지 자기 말로 설명하게 한다.
2. 연구 하나를 읽은 뒤 무엇이 관찰됐고 셀핀다 제품에 무엇을 말할 수 있는지 설명하게 한다.
3. 후기를 찾아 제품·사용 맥락·제공 관계를 확인하고, 사용해 보고 싶은 이유와 망설이는 이유를 각각 묻는다.
4. 첫 사용 정보와 구매 조건을 찾아 친구에게 필요한 링크를 전달하게 한다.

초기 소규모 관찰은 결함 탐색이며 전환 효과 입증이 아니다. 체험 의향이 높아도 자료보다 강한 효능을 확신한다면 수정 대상이다. 후기 열람·공유 시도·공식몰 클릭을 구매 완료로 집계하지 않는다. 실제 구매 전환은 주문 연동 후 평가한다.

## 이번 반영 범위와 남은 일

반영: 첫 화면 제품 정체·실물 및 제품/후기 진입, 상단 후기/연구 메뉴, 750·1500 제품 카드의 후기 경로, 연구 카드 핵심 조건 기본 노출, 후기 제목의 제공 범위 명확화.

후속 반영: 인용 후기의 초안/수정 저장, 저장된 동일 버전에 대한 검토 확인과 승인, 공개 중단, 한국 날짜 기준 권한 만료 필터, 제품별 후기 카드 탐색. 문구 수정은 보류와 확인 초기화를 동반한다. 공식몰 후기 안내 문구는 고정해 인용 후기 검토를 우회할 수 없게 했다.

남음: 권한이 확인된 실제 후기 콘텐츠, 첫 사용 자료, 소비자 관찰, 독립 담당자의 운영 검토. 전체 플랫폼의 회원·추천·주문·AI·영구 배포 등 미완 범위는 COMPLETION_AUDIT.md를 유지한다. 이번 수정은 해당 범위의 완료를 의미하지 않는다.

## 구매 전 질문 모듈 반영

제품 비교 아래에 확인된 사실과 확인 경로를 분리한 구매 전 질문 5개를 추가했다. 750·1500 내용량·구성은 상품명과 제품 이미지 범위로 설명하고, 섭취법·보관·주의사항은 포장 표시사항과 공식몰로 돌려보낸다. 리듬 체크 결과로 용량을 추천하지 않으며, 후기와 연구를 제품 효과 보장으로 연결하지 않는다. 실제 소비자 이해도와 구매 장벽 감소는 별도 사용성 조사로 검증해야 한다.
