# 브랜드·전환 경험 설계 TF 검토 — 2026-09-17

## 검토 범위

사용자가 제공한 전문가 역량 브리프를 `data/tf-role-registry.json`의 새 내부 역할로 연결하고, 현재 사이트 코드의 실제 섹션 순서와 전환 흐름을 기준으로 한 차례 AI 역할별 TF 검토를 진행했다. 이는 실제 외부 전문가 회의, 자격 검증, 소비자 인터뷰 또는 법률 자문이 아니다.

## 코드에서 확인한 사용자 여정

수정 전에는 1분 리듬 체크 직후 뇌 피로 건강 연구 카드가 나타났고, GABA 설명과 티저가 그 뒤에 배치되어 있었다. 방문자가 자기 상황을 확인한 다음 GABA를 먼저 이해하는 흐름보다 일반 연구 정보가 먼저 나오는 구조였다. 한편 영상, 제품 이미지, 발효 과정, 후기 원문 링크, 공유·측정 기능은 이미 구현돼 있었으므로 새 자산을 만들거나 기능을 다시 짤 필요는 없었다.

## 역할별 검토와 결정

| TF 역할 | 검토 의견 | 결정 |
|---|---|---|
| 브랜드·전환 경험 설계 | 첫 체크 직후에는 연구 목록보다 “GABA가 무엇인지”에 대한 짧은 설명이 방문자의 다음 질문에 답한다. | 체크 다음에 GABA 쉬운 설명을 배치한다. |
| 마케팅·소비자심리 | 소비자는 제품 탐색 전에 자신의 상황과 연결되는 설명을 원한다. 신뢰는 제조 과정·제품 표시·구매자 후기 순서로 쌓을 수 있다. | 체크와 쉬운 설명 뒤에 영상·일반 GABA 연구 요약을 두고, 제조·제품·후기 순으로 이어간다. |
| 스토리·UX·프런트 | 영상 뒤의 근거 요약, 그 다음 발효·제품·후기·심화 연구가 기존 기능을 살리면서 흐름을 잇는다. | 기존 섹션과 이벤트를 삭제하지 않고 순서만 재배치한다. |
| 연구·근거 및 제품·표시 | 일반 뇌 피로 건강 연구는 GABA 섭취 연구 또는 셀핀다 완제품 시험으로 혼동되면 안 된다. | 해당 섹션을 핵심 구매 여정 뒤의 선택형 추가 읽기로 이동하고 제목에 범위를 표시한다. |
| QA·감사 | 화면 순서를 소스 검사로 고정해야 이후 수정 때 연구 카드가 다시 앞에 끼어들지 않는다. | `validate:ui-contract`에 소비자 흐름 순서 검사를 추가하고 TF 역할 필수 구성 검사를 일곱 역할로 갱신한다. |

## 적용한 공개 흐름

공감 장면 → 1분 리듬 체크 → GABA 쉬운 설명 → 티저 영상 → GABA 관련 연구 요약 → 발효 과정 → 가바 1500 제품 정보 → 스마트스토어 후기 → 쉬운 연구 자료실 → 선택형 추가 읽기(뇌 피로와 건강) → 7일 챌린지·공유.

뇌 피로 연구 섹션은 `더 알아보기 · 뇌 피로와 건강`으로 표시했다. 연구가 제품 효과를 증명하거나 진단하는 것처럼 보이지 않도록 원래의 설명과 근거 범위 문구는 바꾸지 않았다.

## 변경하지 않은 범위

- 제품 정보, 스마트스토어 URL, 스마트스토어 후기 목적지, 승인된 연구 문구와 실제 후기 기능
- 기존 티저 영상, 제품 이미지, 공유·분석 이벤트, 리듬 체크와 게임 동작
- 소비자 화면의 새 광고 문구나 효능 주장

## 검증 및 한계

정적 UI 계약 검사로 섹션 순서와 보조 연구 섹션의 제목을 확인했다. production build와 TF·연구·공개 데이터 검사가 통과했고 회귀 테스트 96/96건이 통과했다. production preview는 HTTP 200과 HTML 콘텐츠 유형을 반환했다. 공개 Pages에서도 HTTP 200, 승인 주장 14건, 연구 인덱스 8건, 제품 1종, 공유 페이지 6개, TF 운영 작업 14개, 필수 역할 7개, Smart Store only, provenance matched를 확인했다. 최초 배포 smoke가 예전 제목과 작업 수를 기대해 실패한 뒤 검증 기준을 최신 흐름에 맞게 수정했고, 같은 공개 URL에 새 검사기를 실행해 통과했다. 이때는 브라우저 QA를 수행하지 못했다.

## 2차 TF 교차 검토 및 반영 — 2026-09-17

마케팅·소비자심리, 연구근거·표시, 모바일 UX·전환 역할이 변경된 화면을 다시 나눠 검토한 뒤 서로의 의견을 대조했다. AI 역할 기반 검토이며 외부 전문가의 실제 자격 검증, 소비자 인터뷰, 법률 자문을 대신하지 않는다.

| 역할 | 재검토 의견 | 반영 |
|---|---|---|
| 마케팅·소비자심리 | 체크를 마친 사람에게 곧바로 친구 초대를 요구하면 방해가 된다. 쉬어야 할 결과에서는 휴식 행동 하나를 먼저 권하고, 상태가 괜찮은 결과에서는 부담 없는 초대를 보여주자. | 결과에 따라 공유 CTA 우선순위를 분기하고, 휴식 권고가 필요한 경우 공유와 재시작은 접힌 선택지로 이동했다. 초대 문구도 “나 방금 해봤어. 1분이면 끝나. 너도 해볼래?”로 짧게 바꿨다. |
| 연구근거·표시 | 수면 연구 참여자는 일반 성인이 아니라 잠드는 데 어려움을 겪은 성인 40명이며, GABA군 30명과 비교 정제군 10명의 시작 수치도 달랐다. GABA군만 크게 보여주면 맥락을 놓칠 수 있다. | 두 그룹을 같은 단위·축에 나란히 그려 인원수, 시작·4주 뒤 값, 하루 300mg, 4주를 같이 표시했다. 연구 대상 설명을 앞에 두고, 사용 정제와 셀핀다 가바 1500은 별도 제품임을 쉬운 문장으로 바로 덧붙였다. |
| 모바일 UX·전환 | 질문 시작 전에 비슷한 안내와 카드가 반복되며 CTA를 밀어낸다. 초대와 개인정보 안내도 한 번씩 명확하게 보여야 한다. | 시작 화면을 다섯 문항·자동 이동 안내와 하나의 CTA로 단순화했다. 공유 화면은 초대 버튼 하나와 답변 비전송 안내를 유지하고 중복 공유 선택지는 접었다. |

### 검증 기록

이번 실행에서는 Playwright를 사용할 수 없어 설치된 Chrome의 CDP로 production preview를 데스크톱과 390px 모바일 폭에서 확인했다. 모바일 질문의 자동 진행, 결과 단계, 0–15점 뇌 그림 채움 비율, 낮은 총점과 별개인 단일 반복 응답 안내, 공유 개인정보 문구, 시작 전 친구 초대 제거, 두 연구군 도표와 제품 범위 문장을 확인했다. JavaScript 콘솔 오류와 가로 넘침은 발견되지 않았고, 회귀 테스트 96/96건과 production build가 통과했다.

이번 실행으로 실제 소비자 이해도·전환율 개선이 입증된 것은 아니다. 배포 뒤에도 유입, 체크 완료, 공유, 스마트스토어 이동 지표를 보고 다음 수정을 정하며, 구매 후기 문구는 공개 허가된 자료만 사용한다.
