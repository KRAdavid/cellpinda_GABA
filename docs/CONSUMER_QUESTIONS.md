# 소비자 질문으로 묶는 FAQ 설계

2026-09-10 · AI 콘텐츠·소비자 심리 관점의 설계안. 실제 소비자 조사나 효능 검증 결과가 아니다.

## 목적과 배치

긴 홈에서는 각 장면의 핵심 질문 하나에 답하고, 연구 방법·제품 표시·구매 조건의 세부 질문은 해당 장면 가까운 FAQ로 이동한다. ‘기술을 많이 안다’보다 ‘내가 선택할 때 무엇을 확인해야 하는지 안다’를 목표로 삼는다.

홈 공통 FAQ는 제품 비교 뒤에 5개만 두고, 연구 전용 질문은 연구 라이브러리, 제조 문헌 질문은 발효 이야기 상세로 나눈다. 제품 페이지와 일반 성분 연구의 답변을 합쳐 완제품 효과를 추론하지 않는다.

## 홈에 남길 질문 5개

| 질문 | 짧은 답의 방향 | 연결 자료 | 공개 전 확인 |
|---|---|---|---|
| 리듬 체크 결과가 무엇을 알려주나요? | 최근 생활 답변을 편집 규칙으로 묶은 유형. 체내 GABA나 질환·제품 필요성을 측정하지 않음 | 체크의 분류 규칙 | 유형별로 제품·용량을 연결하지 않는지 |
| 몸속 GABA의 역할과 먹는 제품의 효과는 같은가요? | 체내 신호 역할과 섭취 연구를 따로 확인해야 함 | 승인된 기본 정보·연구 상세 | 특정 제품 효과로 일반화하는 문장이나 그림이 없는지 |
| 현재 판매 제품은 어떤 구성인가요? | 현재 공식몰에서 확인한 1포 내용량·포수·총량 비교 | 최신 제품 정보와 공식몰 | 내용량과 순도·효능·권장량 혼동이 없는지 |
| 처음 사용할 때 무엇을 확인하나요? | 최신 포장 표시사항·사용 및 보관 안내 확인 | 앞뒷면 포장, 공식 사용 안내 | 자료가 없으면 임의의 섭취 시점·횟수·혼합 방법을 제시하지 않음 |
| 가격·배송·반품·문의는 어디서 확인하나요? | 최신 조건은 공식 판매처에서 확인 | 검증된 판매처·문의 목적지 | 변동 정보의 확인일과 실제 목적지, 존재하지 않는 체험 혜택을 만들지 않음 |

## 연구 라이브러리의 질문

- **이 자료는 어떤 종류의 연구인가요?** 원장의 studyType을 그대로 보여주고 대상·비교군·기간·지표와 함께 읽도록 한다. 자료 유형은 의학적 효능 태그로 바꾸지 않는다.
- **한 연구의 숫자를 어떻게 읽으면 되나요?** 단위·대상·군 간 비교·불확실성·한계를 함께 제시한다. 전후 평균 차이를 위약 대비 개선율로 바꾸지 않는다.
- **이 연구가 셀핀다 완제품 시험인가요?** 원장의 productApplicability로 답하고 제품별 연결이 확인되지 않았다면 그 범위를 명시한다.
- **연구에서 쓴 양만큼 제품을 먹으면 되나요?** 연구 조건은 제품 섭취 안내가 아니다. 해당 제품의 최신 표시사항으로 연결한다.
- **원문은 어디서 볼 수 있나요?** 공개 URL·연구 제목·문헌 위치와 직접 링크를 제공한다. 검색 결과가 0건이라는 이유로 ‘근거가 전혀 없다’고 결론 내리지 않는다.

## 발효 이야기에서만 다룰 질문

‘균주가 어디서 유래했나요?’, ‘특허가 무엇을 설명하나요?’, ‘이 문헌과 지금 제품은 어떻게 연결되나요?’를 하나의 제조 근거 묶음으로 제시한다. 확인한 문헌 사실과 현행 제품 추적 사실을 분리한다. 특허·시험 수치·시설 인증을 완제품 인체 효과 인증처럼 보이게 하지 않는다.

## 후기에서만 다룰 질문

‘왜 골랐나요?’, ‘어떤 제품을 얼마 동안 사용했나요?’, ‘좋고 아쉬웠던 점은 무엇인가요?’, ‘제공이나 보상이 있었나요?’를 원문 맥락과 함께 다룬다. 현재 자체 후기 인용 권한이 확인되지 않은 경우 공식몰 원문 이동을 유지한다. 연구 결과와 후기 건강 변화를 나란히 놓아 상호 증명처럼 연출하지 않는다.

## 구현 완료 기준

1. FAQ는 제목만으로 답의 범위를 알 수 있고 키보드로 열고 닫는다.
2. 중요한 제품 선택 조건·한계는 접힌 영역만 읽어야 발견하는 구조로 만들지 않는다.
3. 답마다 승인 원장 항목이나 검증된 공식 목적지를 연결한다. 보류로 바뀐 문구는 공개 FAQ에서도 제외한다.
4. 사람 이름·건강상태·개별 답변을 분석 이벤트로 보내지 않는다. 조회 지표로 이해 정확성을 대신 판단하지 않는다.
5. 읽은 사람에게 ‘제품에 대해 무엇을 기대하게 되었나’, ‘아직 확인할 정보는 무엇인가’를 물어 과도한 효능 추론과 구매 전 불확실성을 점검한다.
