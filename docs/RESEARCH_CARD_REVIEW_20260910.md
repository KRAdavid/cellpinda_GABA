## 공개 문구의 기준

- 연구 제목보다 먼저 참가자, 용량, 기간, 비교군, 측정값을 보여준다.
- 급성 혈중 지표를 장기적인 수면·스트레스·근육 발달 효과로 번역하지 않는다.
- 성분 연구는 셀핀다 완제품의 효과·권장량을 의미하지 않는다는 범위를 각 카드에 표시한다.
- 학습·행동 카드처럼 경구 섭취가 아닌 뇌 관찰 연구는 별도 주제로 분리한다.
- 철회 논문과 원문이 확인되지 않은 카드는 데이터 원장에 보류 사유만 남기고 공개 내보내기에서 제외한다.

## 소비자 언어 개정

승인된 8개 연구 카드에는 원문 링크보다 먼저 다음 두 문장을 둔다.

- **쉽게 말하면**: 참가자·조건·관찰 결과를 소비자가 바로 이해할 수 있는 말로 요약한다.
- **내 생활에 연결해 보기**: 연구 조건을 내 생활의 휴식·운동 루틴을 살펴보는 계기로 연결하되, 셀핀다 완제품의 효과나 섭취량을 약속하지 않는다.

카드 아래의 `가바 1500을 내 루틴으로 경험해 볼지 살펴보세요` 이동은 근거를 읽은 뒤 제품 구성을 확인하는 선택지다. 2026-09-11에는 승인 카드의 `hopefulTakeaway`를 연구 조건 확인 → 1500 표시사항 확인 → 내 루틴에 더해 볼지 선택하는 소비자 문장으로 통일했다. `validate-research-copy`도 제품 발견 단어와 확인·선택 행동이 빠진 희망 문장을 배포 전에 거부한다. 연구 결과가 제품 효과를 보장한다는 뜻으로 읽히지 않도록 각 카드의 `productApplicability`와 한계, 상세 원문 링크를 같은 흐름에 유지한다.

## 다음 검토 회의 안건

1. 식품 표시·광고 문구 담당자가 각 `publicText`와 제품 CTA 주변 문구를 재검토한다.
2. 논문 편집 담당자가 PDF·PubMed·PMC의 표본 수와 통계 표현을 다시 대조한다.
3. 소비자 심리 담당자가 ‘무엇이 관찰됐나 → 무엇을 모르는가 → 원문 보기’ 순서가 이해되는지 확인한다.
4. Smart Store 구매 동선에서는 연구 카드의 효과 표현을 제품 보증처럼 읽지 않는지 모바일 화면까지 점검한다.
