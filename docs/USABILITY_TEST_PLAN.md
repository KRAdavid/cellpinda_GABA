# 셀핀다가바 소비자 사용성 점검 계획

이 계획은 사이트가 소비자에게 어떤 순서로 이해되고 어디에서 망설임이 생기는지 확인하기 위한 실행 문서다. 의학적 효과나 구매 전환을 증명하는 조사가 아니며, 문구·정보 순서·제품 선택 화면을 개선하기 위한 관찰에 사용한다.

## 조사 목표

참가자가 다음 흐름을 혼자 수행할 수 있는지 확인한다.

`공감 질문 → 하루 리듬 체크 → GABA 한 문장 이해 → 발효·근거 확인 → 1500 제품 구성 확인 → 후기 원문 이동 → 스마트스토어 이동 또는 결과 공유`

## 참가자와 진행

- GABA 또는 휴식·수면 관련 식품에 관심이 있는 성인 5~7명
- 셀핀다 제품을 만든 사람이나 사이트 제작에 참여한 사람은 제외
- 데스크톱 3~4명, 390px 모바일 2~3명
- 25~30분 개별 진행, 화면 공유와 음성 동의 후 기록
- 건강 상태나 진단 정보를 수집하지 않으며, 언제든 참여를 중단할 수 있게 안내

## 과제

| 순서 | 참가자에게 읽어 줄 과제 | 관찰할 행동 |
|---|---|---|
| 1 | 이 사이트가 무엇을 도와주는지 자유롭게 말해 주세요. | 첫 문장 이해, 제품·정보 사이트 구분 |
| 2 | 자신의 하루 리듬을 확인해 보세요. | 체크 시작·완료, 질문 이해, 결과 해석 |
| 3 | GABA를 친구에게 한 문장으로 설명해 주세요. | 체내 일반 개념과 제품 효과를 혼동하는지 |
| 4 | 셀핀다 발효가바를 신뢰할 때 확인할 정보를 찾아 주세요. | 출처·공정·한계 정보의 발견성 |
| 5 | 현재 판매 제품의 내용량과 구성을 말해 주세요. | 1500 mg·30포·총량 이해, 권장량 오해 |
| 6 | 다른 사람의 사용 경험을 확인해 보세요. | 후기와 연구의 구분, 원문 링크 발견 |
| 7 | 구매 정보를 더 확인하려면 어디로 가야 하는지 찾아 주세요. | 스마트스토어 CTA 발견, 구매와 효능 혼동 |
| 8 | 결과를 공유할 이유가 있는지, 있다면 무엇인지 말해 주세요. | 공유 결과물의 가치와 부담 |

## 기록 항목

각 과제마다 성공 여부, 완료 시간, 첫 클릭 위치, 도움 요청, 잘못 이해한 문장, 망설인 이유를 기록한다. 참가자의 표현은 개인 식별정보와 건강정보를 제거하고 의미가 바뀌지 않는 범위에서만 요약한다.

다음 숫자는 출시 판정이 아니라 개선 우선순위를 정하기 위한 운영 기준이다.

- 80% 이상이 사이트의 목적을 “GABA 자료 모음”이 아니라 자신의 리듬을 이해하는 경험으로 설명
- 80% 이상이 현재 제품을 1500 mg·30포 구성으로 정확히 설명
- 80% 이상이 연구 결과와 개인 후기를 제품 효과 보장으로 해석하지 않음
- 80% 이상이 60초 안에 스마트스토어 이동 경로를 찾음
- 3명 이상이 결과 공유의 이유를 제품 구매 강요가 아닌 자기 이해·친구와의 비교·생활 실천 중 하나로 설명

기준을 충족하지 못하면 결과를 실패로 단정하지 않고, 가장 많이 발생한 오해 한 가지를 문구·배치·상호작용 작업으로 전환한다. 조사 결과는 `data/task-graph.json`의 후속 작업과 결정 기록에 연결한다.

## 검토와 보호

연구·제품·후기 문구의 사실성은 사용성 조사 결과로 승인하지 않는다. 참가자가 효능·치료·용량을 잘못 해석하면 표시·콘텐츠 검토 작업으로 보내고, 사이트 문구를 즉시 바꿀 때는 원장과 검증을 함께 갱신한다. 조사 결과를 구매 전환율이나 제품 효과로 보고하지 않는다.
