# 셀핀다 사이트 3차 마케팅·소비자 심리 검토

작성일: 2026-09-10
상태: 현재 구현을 읽고 작성한 독립 AI 역할 검토. 실제 소비자 시험, 실명 전문가 회의, 임상·법률 검토 결과가 아니다. 여기서 제안하는 관심·이해·체험 의향 변화는 검증할 가설이다.
검토 파일: `src/App.tsx`, `src/components/RhythmExperience.tsx`, `src/components/Admin.tsx`, `data/content-ledger.json`.
이 기록은 읽은 시점의 구현을 기준으로 하며 병행 제작 이후에는 최종 화면과 다시 대조한다.

## 사용자 목적과 이번 판단

사용자는 소비자가 가바에 관심을 갖고, 효능 관련 내용을 쉽게 이해하고, 상세한 근거와 실제 후기를 확인하여 제품을 체험하고 싶어지는 사이트를 요청했다. 최종 목표의 생활 리듬 체크·공유 경험은 이 관심의 입구다.

현재 구현은 체크·생활 유형·PNG 공유·친구 비교로 참여할 이유를 만들었다. 성분의 체내 역할과 섭취 제품의 효과를 분리하고, 실제 공식 구매처까지 연결했다. 그러나 체크 참여를 제품 이해·첫 구매 판단으로 이어주는 사용 정보가 얕고, 자체 후기 콘텐츠는 아직 없다. 사이트가 체험형 마케팅 플랫폼의 기능적 초안을 갖췄다는 평가와, 실제 소비자를 설득하는지 검증되었다는 평가는 구분해야 한다.

‘효능을 쉽게 이해한다’는 목적은 알려진 연구 결과·관찰 조건·불확실성을 자기 말로 설명할 수 있게 하는 것으로 구현한다. 근거가 부족한 상태에서 완제품 효과를 확신시키는 것을 성공으로 두지 않는다.

## 채택을 권고하는 전체 이야기

나의 하루 발견 → GABA 한 문장 이해 → 무엇을 연구했는지 조건과 함께 읽기 → 셀핀다 제품에 실제로 연결되는 사실 확인 → 사람의 사용 경험 → 첫 사용 모습·구매 전 질문 → 구성 선택과 공식 구매처.

체크를 건너뛰고 근거·제품·후기로 바로 갈 수 있게 한다. 모든 방문자에게 긴 체크를 강제하지 않는다. 초기 관심 장면에 후기 맛보기를 넣는다면, 사용권과 맥락을 검토한 선택 이유·사용 편의만 제한적으로 사용한다. 효과 변화 후기와 연구 결과를 인접시켜 서로의 증거처럼 연출하지 않는다.

## 후기 승인 후 들어갈 콘텐츠 계층

후기 입력·검토·공개는 다음 구조를 공유한다. 확인할 수 없는 필드를 창작해 채우지 않고 검토 대기 대상으로 남긴다.

| 계층 | 기본 화면 | 펼쳐 읽는 상세·관리 자료 | 공개 조건 |
|---|---|---|---|
| 선택 배경 | 왜 이 제품을 알아봤는지 짧은 맥락 | 전체 후기에서 그 배경이 갖는 의미 | 과도한 효과 기대를 유도하는 발췌 금지 |
| 실제 제품 | 실제 구매·사용한 제품 구성 | SKU·구매 또는 사용 확인 근거 | 현재 판매 제품과 다른 경우 차이 명시 |
| 사용 기간 | 작성 시점·사용 기간 | 기간 확인 방식, 불명확한 지점 | 날짜를 파일 수정일로 대신하지 않음 |
| 좋았던 점·아쉬운 점 | 편의·맛·포장 등 구체 경험과 한계 | 원문 맥락, 서로 다른 경험 | 긍정 부분만 잘라 의미를 바꾸지 않음 |
| 제공·경제적 관계 | 제품 제공·협찬·보상 여부를 가까이 표시 | 관계 확인 기록 | 확인되지 않은 후기를 자발적 구매 후기처럼 표시하지 않음 |
| 원문 | 원문 읽기와 출처·작성일 | 재게시 동의·인용 범위·검토 이력 | 공개 URL 존재만으로 재인용 권한을 가정하지 않음 |

기본 카드에는 제품·시점·제공 여부와 대표 경험을 함께 표시한다. 상세에는 선택 배경→사용 과정→좋은 점과 아쉬운 점→원문 순서로 둔다. 공개 문구뿐 아니라 제목·발췌·사진·정렬 순서도 함께 검토한다.

기존 로컬 캡처에는 건강 변화 주장, 비동의 사용, 미성년자 등 민감한 맥락이 섞여 있고 사용권·작성 시점이 확인되지 않은 항목이 있다. 보류 자료의 일부를 잘라 ‘선택 이유’로 재포장하지 않는다. 해당 자료의 공개 적합성과 맥락 보존이 확인되기 전에는 공식몰 원문 이동을 유지한다.

후기는 개인 경험을 구체화하는 자료다. 제품 시험 결과나 대표적 소비자 결과로 제시하지 않는다. 가상 후기·가짜 작성자·임의 평점·근거 없는 만족률·현재 구매자 수·구매 알림·품절 압박을 만들지 않는다. 사회적 증거의 숫자를 사용하려면 집계 기간·모집단·중복·보상 여부·원천 자료부터 확인한다.

## 구매 전 질문과 체험 전환 개선 3개

### 1. 구성 비교 직전 ‘첫 개봉부터’ 모듈

현재 제품 카드의 숫자만으로 첫 사용을 상상하기 어렵다는 가설이다. 실제 포장 앞뒷면, 크기를 알 수 있는 실물 촬영, 개봉 방식, 확인된 표시사항과 보관 안내를 3장 이내로 정리한다. 맛은 제조사 확인 설명 또는 검토 완료 개인 경험으로 출처를 구분한다. 제품을 사용해보지 않은 AI의 시음 서술은 쓰지 않는다.

완료 조건: 각 설명과 이미지에 실제 제품·최신 표시사항·사용권이 연결되고, 방문자가 무엇을 받는지와 어디서 사용 안내를 확인할지 설명할 수 있다. 준비 자료가 없으면 결과 화면을 채우기 위해 임의의 섭취법을 넣지 않는다.

### 2. 구매 버튼 위의 다섯 질문

‘어떤 제품 구성이 있나요?’, ‘내용량과 성분 함량은 같은가요?’, ‘섭취·보관 안내는 어디서 확인하나요?’, ‘가격·배송·반품 조건은 어디서 확인하나요?’, ‘추가 질문은 어디로 하나요?’를 짧은 답과 공식 확인 경로로 구성한다. 현행 정보가 확인된 항목만 답하고 변동 정보는 공식몰에서 확인하도록 연결한다.

버튼은 도착점을 정확히 나타내는 ‘공식몰에서 구성·재고 확인’을 유지한다. 실제 체험팩·신청 프로그램이 확인되지 않았다면 무료 체험을 암시하는 명칭을 사용하지 않는다. 리듬 유형으로 특정 SKU·내용량을 추천하지 않는다.

완료 조건: 방문자가 현행 상품 조건과 문의 경로를 찾을 수 있고, 버튼 클릭 전 외부 스마트스토어 이동임을 안다. 외부 이동 수는 구매 수와 별도로 집계한다.

### 3. 후기에서 ‘내가 확인할 정보’로 복귀하는 경로

승인된 후기 카드 아래에 ‘이 후기의 제품 구성 확인’과 ‘첫 사용 정보 보기’를 배치한다. 아직 자체 후기가 없으면 스마트스토어 후기 링크 옆에 선택 배경·제품·기간·아쉬운 점을 읽는 질문을 유지하고, 돌아온 방문자가 제품 비교를 바로 찾게 한다. 후기를 읽고 곧바로 효과 확신을 요구하는 문구 대신 실제 사용 조건 확인으로 연결한다.

완료 조건: 후기와 연결된 제품이 정확하고, 후기 상세를 닫으면 이전 읽기 위치를 유지하며, 후기 선택 이유와 개인 건강 변화가 혼동되지 않는다. 후기 원문 이동이 실제 후기 독서 완료임을 전제하지 않는다.

## 검증 질문과 의사결정

실제 사용자에게 ‘이 제품에서 무엇을 기대하게 되었나요?’, ‘그 기대는 어떤 설명에서 생겼나요?’, ‘일반 성분 연구와 이 제품 자료는 어떻게 다른가요?’, ‘구매 전에 아직 모르는 것은 무엇인가요?’를 묻는다. 관심·체험 의향만 높은 결과보다 이해 정확성과 남은 구매 장벽을 함께 기록한다.

- 마케팅 관점: 체크 참여율만 높이는 개선보다 제품 이해·공식 정보 확인으로 이어지는지 관찰한다.
- 심리 관점: 후기와 개념 애니메이션이 근거 범위를 넘는 확신을 만드는지 확인한다.
- 근거 담당에게 요청: 승인 원장 metadata를 소비자 질문 순서로 재배치하되 중요한 한계는 숨기지 않는다.
- UX·개발 담당에게 요청: 원장에 연결된 콘텐츠 렌더링을 통일하고 제품·후기·근거를 주제별로 분리한다.
- 사업 책임자에게 필요한 입력: 현재 제품 표시사항, 첫 사용 촬영, 실제 상담 경로, 후기 재게시 권한과 제공 관계, 체험 프로그램 존재 여부.

## 메인 제작팀에 전하는 우선 권고

1. 승인 원장의 연구 metadata·후기 공개 상태가 실제 화면을 결정하도록 연결한다.
2. 제품 비교 앞에 실제 첫 사용 정보와 구매 전 질문을 보강한다.
3. 후기 자료를 확보한 뒤 검토된 경험을 깊게 보여준다. 현재는 공식몰 원문 이동을 정직하게 유지한다.

이번 기록에서 새로 소비자 조사나 전문 자격 검토를 실시한 것은 아니다. 제안만으로 전환율 향상이나 체험 의향 증가를 단정하지 않는다.


## 병행 제작 후 반영 확인

ResearchLibrary/ReviewExperience와 Node·Worker 공개 원장이 연결되었다. 연구 요약 하드코딩과 발효 영역에 연구가 섞이는 문제를 수정했다. 후기 링크는 승인된 1500 목적지를 공개하며 홈·제품 비교 카드에서도 1500 제품 원문 진입점을 제공한다. 실제 고객 인용은 여전히 공개하지 않는다. 공개 서버에서 연구2건 상세 열기·후기 새창·제품 복귀·390px 가로 넘침 없음·콘솔 오류없음을 검증했다. 연구 상세 CSS 격자 충돌을 수정하고 재배포·재검증했다. 재게시 가능한 실제 후기와 첫 사용 자료는 여전히 필요하다.
